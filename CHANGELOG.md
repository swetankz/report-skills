# Changelog

All notable repository-level changes are documented here.

## 0.2.0-rc.1 — 2026-08-21

- Resolve and profile exactly one native Codex implementation, reproduce the package wrapper's managed environment, and bind every model-backed call to kill-on-timeout process-tree handling plus canonical stage-specific timeout and termination receipts. Failed calls stop their stage and cannot be graded, compared, resumed, or salvaged from terminal-looking output.

- Add reproducible paired behavioral, blind-comparison, adversarial, and activation evaluation contracts for all eleven skills.
- Bind live evaluation evidence to a clean commit and tree, tracked skill and fixture hashes, canonical contract hashes, and one explicit model, reasoning, CLI, and runtime profile.
- Bind every task contract and persisted task artifact set before downstream review; use immutable grader-attempt receipts, input/output hashes, source-bound blind bundles, one deterministic blind seed, and independent aggregate-time grade/comparison revalidation so partial or altered evidence cannot be retried or change a release gate.
- Parse every canonical fixture CSV before a dry-run plan is emitted or any live call begins, and parse every produced CSV artifact before grading; reject width mismatches and zero-field or whitespace-only logical records, so visually reconstructable but structurally corrupted data cannot satisfy a release gate.
- Require evidence-first review and revision passes to register every introduced derived quantity, date interval, input, calculation, and unit before it enters prose, or omit the quantitative wording when support is incomplete.
- Add release thresholds, schemas, runners, aggregation, focused tests, CI contract checks, and public methodology documentation while keeping raw transcripts local and untracked.
- Validate every model-facing object schema against the strict structured-output requirement before live evaluation.
- Allow task agents to create local benchmark artifacts through automatic approval review constrained to the isolated `workspace-write` sandbox.
- Add a defense-in-depth check that rejects named `SKILL.md` path references outside the injected candidate when they are visible in top-level command events, and record path-free local loader diagnostics.
- Version and bind the exact canonical method for behavioral tasks, graders, blind comparators, and trigger observations in every upstream and aggregate receipt. Each model stage now uses a fresh external system-temporary directory for only its filesystem-visible inputs, copied schema, and temporary output, while supplying the versioned prompt only to that call; pre/post input hashes, regular-file hash-matched copyback, and cleanup are revalidated before reuse or aggregation. Release-defining calls disable multi-agent delegation, while task execution additionally fences ambient Git discovery and rejects repository-boundary commands or disclosures, fabricated integrity events, and external mutation.
- Separate focused Gate 1 RC preparation from Gate 2 final qualification with a tracked Gate 1 plan and no-retry orchestrator that freezes all 25 calls before execution, completes the exact mixed-repetition 15-observation routing canary first, then interleaves each of five adversarial/security tasks with its perfect-grade check before starting the next task. Bind five one-case roots and the trigger root through an immutable master plan and hashed completion summary; the read-only validator refuses missing or reordered calls, retries, blind comparisons, or a Gate 2 aggregate. Gate 2 retains the 96 tasks, 96 graders, 33 blind comparisons, and 75 trigger observations required for the full benchmark verdict.
- Require catalog-first, body-proven skill activation with one exact-token-bounded exception: a validated canonical token in the raw request may load only its exact workspace `SKILL.md`, while no-token cases cannot use filesystem, metadata, frontmatter, partial-read, or alternate-path discovery fallbacks.
- Store observations and blind-comparison bundles under compact physical directories while retaining canonical logical identities, and fail before model calls if a copied fixture or injected-skill input would exceed the safe Windows path budget.
- Build both public archives from a clean-HEAD, regular-Git-blob allowlist; reject tracked raw evaluation trees and non-regular entries while excluding ignored or untracked local material, and independently verify ZIP ordering, fixed metadata, manifest hashes, checksums, inventory, and double-build reproducibility.
- Preserve tracked fixture and skill hashing in the history-free source snapshot through its verified file manifest, so extracted validation does not depend on a `.git` directory.
- Treat quoted search patterns as data rather than executed Git commands in trace isolation checks, while recursively validating quoted shell command payloads; bind the corrected classifier to evaluation method `report-skills-release-evaluation-v3`.
- Disable both Codex multi-agent feature paths and set `agents.enabled=false` for every release-defining call, reject alternate profiles plus noncanonical or compound configuration overrides, inspect the model-visible prompt from a fresh external temporary directory before spending evaluation tokens, fail closed on an unexpected prompt schema, empty developer content, or sentinel, bind a deterministic normalized developer-context hash across execution receipts, add no-collaboration prompt guards to graders and trigger observations, and bind the strengthened isolation receipt to evaluation method `report-skills-release-evaluation-v4`.
- Stop optional host-capability discovery after missing release evidence conclusively blocks an external action, reject direct command records using common executed discovery forms (`Get-Command`, `Get-Module -ListAvailable`, `command -v`, `which`, and `where.exe`) without misclassifying quoted search text, leave compound shell records to semantic safety review, and bind the stricter boundary classifier to evaluation method `report-skills-release-evaluation-v5`.
- Treat an explicit ripgrep `.git` exclusion glob as filtering rather than metadata access while continuing to reject inclusive or direct `.git` paths, and require safe ambiguous external-action stops to be reported as blockers rather than integrity events; bind both corrections to evaluation method `report-skills-release-evaluation-v6`.
- Require release verification and behavioral tasks to materialize plain workspace-local text or project primitive scalar evidence before serialization, deterministically reject coherent PowerShell provider metadata in command output, and bind the strengthened output guard to evaluation method `report-skills-release-evaluation-v7`.
- Make unwrapped trace-command host-discovery classification independent of the validator operating system by applying both PowerShell and POSIX grammars, normalize shell logical-line continuations before wrapper detection, cover static assignment/redirection prefixes plus standard `command` `-p/-v/-V` option clusters, preserve the existing quoted-search fixtures, add targeted Windows CI coverage, and pre-screen multiline heredoc-shaped records before quote handling so discovery-shaped content fails closed without duplicating shell parsing; bind the corrected boundary guard to evaluation method `report-skills-release-evaluation-v8`.
