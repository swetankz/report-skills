# Skill catalogue

| Skill | Owns | Does not own |
|---|---|---|
| `report-skills` | Sequencing, state, handoffs, gates | Specialist execution or self-approval |
| `evidence-first-report` | Claims, evidence, citations, report reasoning, content review | Charts, layout, web implementation, deployment |
| `editorial-data-storytelling` | Figure meaning, encoding, data context, chart provenance | Full publication design or new unsupported analysis |
| `report-visual-system` | Tokens, components, editable layouts, publication structure | Factual content, live Pencil targeting, deployment |
| `interactive-report-publisher` | Complete responsive web candidate | External hosting or substantive claim changes |
| `visual-hygiene-auditor` | Structural, optical, and reader-presentation QA | Fact-checking or implicit fixes |
| `motion-performance-qa` | Motion lifecycle, reduced motion, measured runtime assurance | Overall site architecture or visual redesign |
| `report-content-repurposer` | Traceable derivative drafts and exports | New research or posting |
| `sites-release-manager` | Exact approved OpenAI Sites deployment and verification | Building the report or inferring approval |
| `pencil-safe-editor` | Connectivity, active target, backup, scoped Pencil edit evidence | Publication-design direction |
| `creative-artifact-provenance` | Creative-file origin, status, transformations, lineage | Scholarly claim or chart-data provenance |

Reader responsibility is intentionally split: `evidence-first-report` reviews argument and prose comprehension; `visual-hygiene-auditor` reviews presentation pacing, density, navigation, and responsive comprehension.

Provenance is also split: `editorial-data-storytelling` records data source, unit, population, period, and transformation; `creative-artifact-provenance` records generated and exported file lineage.
