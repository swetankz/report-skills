# Synthetic CivicAssist Pilot

This fixture is entirely fictional. It exists to evaluate Report Skills without using private, current, or third-party report material.

The scenario asks whether a fictional city service team should pilot a digital appointment assistant. Dates, organizations, evidence, identifiers, statistics, release records, Pencil states, and provenance data are synthetic.

`inputs/` contains usable evidence. `intentional-defects/` contains deliberately flawed or adversarial inputs that skills must identify rather than propagate, including an untrusted source-instruction example. `website-fixture/` contains a deliberately defective local page for QA exercises.
